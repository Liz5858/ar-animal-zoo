# 우리 교실 AR 동물원

PC 웹캠 영상 위에 3D 동물을 배치하는 수업용 웹 앱입니다.

- 공룡·토끼·고양이·사자 소환
- 클릭으로 배치, 드래그로 이동
- 점프·회전·방향·크기 조절
- PNG 사진 저장

카메라를 켜지 않아도 연습할 수 있습니다. 카메라를 사용할 때는 Chrome 또는 Edge에서 권한을 허용하세요. 카메라 영상은 이 앱에서 서버로 전송하지 않습니다.

실제 바닥이나 책상 표면을 추적하지 않는 카메라 합성 방식입니다. 카메라를 고정해 사용하세요.

Three.js 0.160.1을 jsDelivr에서 불러오므로 인터넷 연결이 필요합니다.
